# Omniverse Gaussian Splat Converter

Converts 3D Gaussian Splat data (`.ply` and `.spz`) to USD using the
`ParticleField3DGaussianSplat` schema.

Installation, command-line usage, the Python API and supported formats are
documented once, in the package readme that ships with the wheel:

**[`source/python/README.md`](../source/python/README.md)**

That file is what `pyproject.toml` publishes as the PyPI landing page, so it is the
copy that stays current. This page links to it rather than repeating it.
